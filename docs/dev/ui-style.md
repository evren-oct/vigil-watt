# 界面视觉规则

> 改界面、加颜色、加图标之前先读本文。色值的唯一来源是 `src/VigilWatt.App/Services/UiPalette.cs`，
> 字号与卡片样式在 `App.xaml` 的资源字典里；本文只写**规则和为什么**，值变了以代码为准。

## 1. 总原则：颜色只表达电量状态与可操作

四档状态色（绿 / 琥珀 / 红 / 蓝）是**全局同一把尺子**，各界面共用同一组色值，不做按设备、按品牌、按用户偏好的自定义颜色。

原因：低电量气泡只在跨阈值时弹一次，**红色是之后唯一的持续提示**。允许改色等于允许静默关掉告警。

由此派生出两条推论：

- **设备身份不靠颜色区分**，靠图标形状（见 §5）。
- **来源（蓝牙 / 2.4G / 有线 / 本机）用独立色相**，且刻意避开状态色的红绿琥珀，免得"这是来源还是电量"分不清（见 §3）。
- **交互色固定品牌蓝**：浅色 `#0071E3`、深色 `#2997FF`，不跟随系统强调色，避免和充电蓝 / 良好绿串味。
- **装饰性用色退场**：分组标题、分区标题不画 accent 竖条，只用中性灰。

## 2. 电量状态色

| 语义 | 色值 | 取值条件 |
|---|---|---|
| 充电中 | `#0A84FF` | `charging == true`，优先于电量档位 |
| 低电量 | `#E2445C` | `percent <= 20` |
| 中电量 | `#FAAA17` | `percent <= 50` |
| 良好 | `#34C759` | `percent > 50` |
| 离线 / 无读数 | `#8E8E93` | `percent == null`，或 `IsOnline == false` |

- 阈值的单一来源是 `UiPalette.BatteryLevel()`；不要在页面里另写一份 `if (p < 20)`。
- 多系列图表循环取色用 `UiPalette.SeriesColors`（首位是充电蓝，作为主系列色）。

## 3. 来源徽标色

| 来源 | 色值 | 说明 |
|---|---|---|
| 蓝牙 | `#0A84FF` | 蓝牙的通用色 |
| 2.4G | `#AF52DE` | 紫，与蓝牙蓝拉开 |
| 有线 | `#5E7C99` | 钢蓝灰，比蓝牙更暗更灰，不抢色相 |
| 本机 | `#30B0C7` | 青 |
| 未知 | `#8E8E93` | **与离线共用同一个灰**，表示"没有信息"而不是"某种链路" |

徽标是**胶囊底 + 同色文字**：底色取同色 16% 不透明度（`UiPalette.Tint()` 默认 `alpha = 0x28`），明暗主题下都够淡，不抢电量条。

徽标本身写着「有线」「2.4G」等文字，**颜色只做辅助**，不是唯一信息载体。

徽标统一高 20、圆角 10、`Padding=8,0`、11 Medium；体系标签（Bolt / Unifying）用中性灰，不跟链路色，链路徽标才承载来源色。

## 4. 指标标签色（DPI / 档位 / 回报率）

| 指标 | 色值 |
|---|---|
| DPI | `#1D9E75` |
| 档位 | `#BA7517` |
| 回报率 | `#534AB7` |

- **只给标签上色，数值保持主题前景色**。颜色当路标用，不让彩色数字跟右侧大号百分比抢注意力。
- 三个色相刻意避开来源徽标（蓝/紫/青）与状态色（红/琥珀/绿/蓝/灰），取更深的中间调。
- 未获取的项用灰（`Offline`），不上色。

## 5. 图标：形状承载身份，颜色承载电量

- **设备类型图标**取自 **Tabler Icons 3.31.0**（MIT）的官方 outline 路径，统一 `24×24` 网格、`1.6` 描边；列表显示 28px，详情 Hero 显示 80px / `0.9` 描边（`DeviceIconFactory.Scaled` / `Hero`）。路径原文在 `Services/TablerDeviceIcons.cs`，解析一次后同时供 XAML 与 GDI+ 使用，不要手画近似形。
- **图标颜色跟随电量状态色**（`IconColor = UiPalette.BatteryLevel(...)`），不是中性色——所以"形状 = 这台是什么，颜色 = 它还有多少电"。
- **接收器体系标签**（Bolt / Unifying 等）用中性灰小尺寸，跟在链路徽标之后；目录没登记就整块不占位。
- **侧栏导航图标**同属 Tabler：`Assets/tabler-icons.ttf` 是只含 6 个字形（电池 / 柱状图 / 数据库 / 脉冲 / 滑块 / 信息圈）的子集，`FontIcon` 直接跟随导航项前景色与选中态；换图标时重新子集化，不要退回 `PathIcon` 手画。
- **设备图标不用字体**：同一图形要在 28px 与 80px 两档按尺寸改描边，还要在任务栏贴片里走 GDI+，字体两者都做不到；用路径才能一处数据、两处渲染。
- **图标选择器**（设备外观对话框）整块卡片就是单选项：圆角 10、`SubtleFillColorSecondaryBrush` 底、选中态 `1.5` 描边 + 8% 强调色底；不要留默认单选圆点，也不要只给图标加个圈。
- **详情页 Hero 可以用厂商产品图**：图只表达“这是什么设备”，不参与电量状态取色；没有图或解码失败时回退同一套几何图标。图片放在中性卡片底上，不按品牌加底色；悬停时右下角出现调整按钮，只改配色，不另开设置页（格式见 [../project/device-images.md](../project/device-images.md)）。
- `bolt` / `unifying` 直接复用 **OpenLogi** 的官方 path 原文（MIT, Copyright (c) 2026 AprilNEA），不是手绘近似；其余体系（Nano / LIGHTSPEED / 27MHz）为自绘几何。**范围仅限设备列表的小尺寸体系标签**，不用于应用图标、安装包或宣传物料。
- 画好的图标元素**不能存进行模型**：行复用会把同一个元素交给第二个容器（`runtime-pitfalls.md` §22）。每个行容器各持一个 presenter 实例。

## 6. 字体与字号

字体**钉死 `Segoe UI`**（`ContentControlThemeFontFamily` / `TextControlThemeFontFamily`）。Win10 没有 `Segoe UI Variable`，用系统默认字体在 Win10 上会宽 5~8%，排版走样（`runtime-pitfalls.md` §13）。

| 字号 | 字重 | 用途 |
|---|---|---|
| 32 | 700 | 页面标题、详情 Hero 设备名 |
| 22 | 700 | 电量百分比、KPI、指标数值 |
| 17 | 500 | 设备名、步骤标题 |
| 15 | 400 | 正文、设置行标题、属性值、页面副标题 |
| 13 | 500 / 400 | 分组标题 500；说明、脚注 400 |
| 11 | 500 | 字段标签、胶囊 |

字重只有 400 / 500 / 700 三档，没有 600。新增字号前先问：现有的六档够不够？多一档字号就多一套对齐要维护。

## 7. 卡片与间距

- 通用卡片 `AppCardStyle`：圆角 12、`CardBackgroundFillColorDefaultBrush` 底、**不画描边**。各页共用，不要各自重复写属性。
- 需要内边距的卡片用 `AppCardPaddedStyle`（`Padding=20`）；设置行、列表行自己写 18~20 的内边距。
- 页面内边距 上 24 / 左右 40 / 下 88，内容最大宽 900，区块间距 24，全部落在 4px 网格。列表自滚的页面（历史管理、设备诊断）下边距用 24，不给固定高度的列表留空。
- 设备行内：图标与内容列间距 18，内容列内元素间距 12，同行徽标间距 8。

## 8. 中性色一律走 ThemeResource

文字、卡片底、分隔线、描边**不用硬编码色值**，一律 `ThemeResource`（`TextFillColorPrimaryBrush` / `TextFillColorSecondaryBrush` / `TextFillColorTertiaryBrush` / `CardBackgroundFillColorDefaultBrush` / `CardStrokeColorDefaultBrush`）。

只有**状态色、来源色、指标色**是固定值，因为它们在明暗主题下要表达同一个语义。

## 9. 系统版本差异

Win10 与 Win11 的视觉能力不同，降级规则记在 `runtime-pitfalls.md`：Mica 不支持会出双标题栏（§13）、小组件在 Win10 上圆角与投影表现不同（§14）、任务栏贴片只能靠 `SetWindowPos(HWND_BOTTOM)` 钉住（§15）。

**改视觉前先在两套系统上各看一眼**，本机只有一套系统时，把未验证的那一半写进 BACKLOG，不要当成已完成。

## 10. 动效

悬停、开关、箭头 200ms；切页淡入 220ms（首屏不播）；分组折叠 260ms；进度条宽度 300ms。统一缓动 `cubic-bezier(.4,0,.2,1)`，并尊重系统 `UISettings.AnimationsEnabled`。

## 11. 不要做的

- 不加按设备 / 按品牌的自定义颜色（§1）。
- 不给电量状态加第五档，或改阈值（阈值只有 `UiPalette.BatteryLevel` 一处）。
- 不用颜色作为唯一的信息载体：徽标要带文字，图表要有数值。
- 不为了"好看"改状态色值——那是告警语义，不是装饰。
- 不给分组标题加装饰竖条；不在页面级元素上套卡。
- 不新增字号档位或卡片样式，除非现有六档 + 一种卡片确实表达不了。
- 复选框圆角 6px 是**语义例外**（12px 会把方框钳成圆形，和单选撞语义），不要当 bug 改回去。
