# GANSS GS3104T-Pro 电量

## 1. 2.4G 协议与来源

官方 GANSS 客户端 Beta 1.0.0.3 的设备配置、静态互操作性分析和官方通信抓包相互印证。
VID/PID 05AC:024F，MI_03，Usage FF60:0061，Windows 输入/输出长度 33（含零 Report ID）。
32 字节线级请求为 20 01，零填充，最后一字节 21；响应例 20 01 00 61，零填充，最后一字节 82。
线级索引 3 的 61 为十进制 97；最后一字节为前 31 字节求和的低 8 位。
Windows 报文额外在最前面放一个 00。不能将这个格式用于其它接口。
官方电量显示使用该字段；解析接受 1–100，拒绝 0 和超过 100。充电状态尚未确认，保持 Unknown。

## 2. 安全与生命周期

独立 Ganss 插件默认关闭，开启后仅发送已捕获的固定电量查询。
复用 BatteryPluginBase 的认领、释放、失败熔断和递增退避；每轮一次请求，500ms 写等待、750ms 读窗口，正常轮询 60 秒。
没有会话配置、命令枚举、其它集合探测或变体重试。验证时正常退出官方客户端，避免争用。
基类只新增可覆盖的 MinValidPercent，默认仍为 2；Ganss 使用 1，防止合法 1% 被过滤。
