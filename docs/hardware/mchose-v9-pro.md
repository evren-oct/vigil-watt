# MCHOSE V9 Pro 2.4G 电量

## 1. 协议来源与接口

官方 MCHOSE HUB 显示 100% 时的 USB 抓包取得一组固定查询和响应，响应约 27ms 后到达。
VID/PID 291D:385D，MI_00 / Col05，Usage FF90:0001，输入/输出长度均为 64，Feature 长度 0。
输入 Report ID 55，扫描器从输入 caps 回退取得；官方实际输出同样以 55 开头。
64 字节请求：55 65 01，余下 61 字节为 00。
64 字节响应：55 65 64 02，余下 60 字节为 00。
长度已包含非零 Report ID，不加前置零。响应索引 2 为 100%，索引 3 的 02 含义未校准。

## 2. 实现与安全

MchoseV9Pro 是独立于 Mchose 键盘的插件，默认关闭；写点检查开关和完整接口。
继承 BatteryPluginBase，复用认领、释放、退避和过滤；仅使用这条已捕获固定请求，不枚举命令。
60 秒轮询，每轮一次请求，500ms 写等待，750ms 读窗口，不启用快速发现或独立后台循环。
解析电量 1–100；0 含义未确认，不作为在线 0%。充电状态始终 Unknown。
基类 MinValidPercent 默认保留 2，此插件覆盖为 1；相关过滤回归同时提供。
测试读取前正常退出 MCHOSE HUB，避免争用接收器。
