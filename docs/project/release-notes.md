# 更新日志（用户向）

> **这份是给用户看的**，不是 changelog。`changelog.md` 记开发过程与原因，这里只写"用户能感知到什么变化"。
> 三个消费方共用本文件：`build-installer.ps1` 截当前版本段传给 `vpk pack --releaseNotes`、`publish-gitee.ps1` 用作 Release 正文、应用内关于页与更新确认框直接渲染。
>
> **格式契约**（解析器只认这四种行，改格式先改 `Services/ReleaseNotes.cs` 与两个打包脚本）：
> 1. `## <版本号>` 开一段，版本号必须与 csproj 的 `<Version>` 三段完全一致；
> 2. 版本标题下可选一行 `YYYY-MM-DD`；
> 3. 条目以 `- ` 开头，一句话，说人话——不写类名、文件路径、内部术语；
> 4. 空行忽略。不支持行内加粗、链接、表格、缩进子列表。
>
> 第一个 `##` 之前的内容只给维护者看，应用不渲染。发版前把当前版本段补上，否则应用内显示"本版本没有更新说明"。
