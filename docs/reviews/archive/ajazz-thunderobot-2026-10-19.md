# 黑爵 / 雷神电量适配审查

## 1. 基线与边界
基于 46efacb，贡献者 KNA7022，仅含品牌电量插件、协议解析、配置与测试。硬件查询已实机验证；同步后的构建执行回归测试，不包含任务栏功能。

## 2. 发现
迈从原有宽泛接口规则曾抢占雷神；当前使用上游 VID 白名单，本改动增加两款接收器不被误认的回归用例。

## 3. 复核
R1/R2：默认关闭，继承 BatteryPluginBase，写入受 WritesEnabled / CanWrite 控制。R3/R4：复用基类 IO 锁、熔断、退避及句柄释放。R5/R7/R8：沿用 IO 日志，异常帧不更新读数，解析纯函数有测试。独立分支构建零警告零错误，29 项相关测试通过。

## 4. 未证实
充电状态保持 Unknown，其他固件及有线/蓝牙模式未验证。开关机查询实机证据见硬件文档。

## 5. 结论去向
无新增未修代码缺陷；协议与边界见 `docs/hardware/devices/ak870-ml903.md`。
